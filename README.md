# Practical Game Presentation 1

Многопрезентационный проект на [reveal.js](https://revealjs.com/) для интерактивных занятий в 5–10 классах.

## Быстрый старт

```bash
npm install
npm run dev
```

Откройте адрес из терминала. Каталог находится на `/`, демо — на `/presentations/demo/`.

## Как добавить презентацию

1. Скопируйте папку `presentations/demo`.
2. Переименуйте её латиницей: например, `morfologiya-5`.
3. Измените `index.html` и `main.js` внутри новой папки.
4. Добавьте карточку презентации в корневой `index.html`.
5. Проверьте проект командой `npm run build`.

Подробные правила, запреты и безопасный процесс описаны в `AGENTS.md`.

Экспедиция «Точка»

Космическая станция потеряла шесть навигационных модулей. Вернуть их смогут только команды, которые умеют читать и собирать предложения.

Миссия: пройти шесть отсеков и набрать как можно больше звёздных очков.

ПЕРЕД СТАРТОМ

Как проходит командная гонка

  1. Учитель делит класс на две команды и выбирает их названия.
  2. Команда обсуждает ответ, затем капитан нажимает вариант.
  3. За верный ответ команда получает 2 очка, за ответ после подсказки — 1 очко.
  4. После каждого отсека объясняем, какое правило помогло.

Важно: счёт работает на общем экране учителя. Это режим командной игры без передачи данных в интернет.
